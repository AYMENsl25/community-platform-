# Policy versioning and approval

Policy pages carry a publication version. User rows carry the terms, privacy, organizer-rules, and community-rules versions they accepted. The deployed `current_*_version` settings are the latest **material** versions that require consent.

- Editorial corrections, translation improvements that do not change meaning, formatting, and contact-detail corrections publish a new document version without changing the required acceptance version.
- Changes to collected/used/shared/retained data, user obligations, eligibility, organizer duties, moderation consequences, cancellation rights, or dispute/legal terms are material. They require legal/product approval, a new required acceptance version, release notes, and a blocked capability flow until acceptance.
- Never change required versions before every locale is approved and available. Never backdate acceptance or infer it from continued use.
- The draft policy-center version is `2026-08-15-draft`. Existing required acceptance versions remain `2026-07-11` until approval determines the final material versions.
